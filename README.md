# 市政道路施工封路方案协调与审批平台

源提示词编号：11。支持分段封路范围、施工阶段、绕行路线、车道收窄和临时设施的同一地图协作；检查相邻工程、救护通道、公交覆盖和绕行时延冲突；提供图层开关、路线绘制、阶段时间轴、条件会签、版本比较和公开通告包导出。

## 通行账（/ledger）

把施工阶段、绕行路线、会签意见和公开通告接成同一本"通行账"，规则见 `src/ledger/engine.ts`（纯函数引擎，45 项自检覆盖全部规则）：

- **保底额度优先**：每个半小时窗口先扣急救、公交最低班次保留额度，施工申请只在剩余容量中预占；
- **超额排队**：放不下的申请进入队列并标明占用来源（急救/公交保底、各施工请求号各占多少）；
- **首写生效**：同一窗口两人同时提交时，首写者生效、后到者留冲突并标明首写来源，不扣额度；
- **原号续跑**：失败后凭原请求号续跑，不重新发号、不重复扣额度；容量腾让时排队项自动升入预占；
- **变更失效**：阶段时间或绕行路线一变，输入指纹 +1，预占全量重算、会签失效、通告草稿作废、窗口核对清零；
- **通告闸门**：存在排队/冲突、未核对窗口未清零、或会签缺失/失效时，通告一律无法出具。

