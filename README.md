# 市政道路施工封路方案协调与审批平台

源提示词编号：11。支持分段封路范围、施工阶段、绕行路线、车道收窄和临时设施的同一地图协作；检查相邻工程、救护通道、公交覆盖和绕行时延冲突；提供图层开关、路线绘制、阶段时间轴、条件会签、版本比较和公开通告包导出。

## 通行账（Traffic Ledger）

把施工阶段、绕行路线、会签意见和通告接成一本按半小时窗口分配路面额度的账：

- **急救/公交最低班次留额度**：每窗口按阶段容量预留急救与公交最低班次额度。
- **施工按剩余容量预占**：施工/交警申请按剩余容量预占，超额部分排队并标明占用来源（急救预留 + 公交预留）。
- **失效重算**：时间或绕行一变，预占、会签、通告草稿立即失效并重算。
- **首写生效，后到留冲突**：两人同时提交同一窗口，首写生效，后到保留冲突记录。
- **按原请求号续跑**：失败后按原请求号重试，幂等不重复扣减额度。
- **未核对窗口清零前不出通告**：排队清零、窗口核对通过后方可发布通告。
